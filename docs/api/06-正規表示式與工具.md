## java.util.regex：Pattern 與 Matcher

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
```

```java
Pattern code = Pattern.compile("[A-Z]{2}\\d{4}");
boolean valid = code.matcher("AB1234").matches(); // 全文必須符合
Matcher matcher = code.matcher("編號 AB1234 與 CD5678");
while (matcher.find()) { // 逐段搜尋
    System.out.println(matcher.group() + " at " + matcher.start());
}

Pattern pair = Pattern.compile("(?<key>[a-z]+)=(\\d+)");
Matcher item = pair.matcher("count=12");
if (item.matches()) {
    String key = item.group("key");
    int value = Integer.parseInt(item.group(2));
}
```

| 規則 | Regex | Java 字串寫法 |
|---|---|---|
| 數字 | `\d` | `"\\d"` |
| 空白 | `\s` | `"\\s"` |
| 任意字元（預設不含行終止符） | `.` | `"."` |
| 字面上的點 | `\.` | `"\\."` |
| 英文字母 | `[A-Za-z]` | `"[A-Za-z]"` |
| 否定字元組 | `[^0-9]` | `"[^0-9]"` |
| 重複次數 | `+`、`*`、`?`、`{2,5}` | 1 次以上、0 次以上、0 或 1、2～5 次 |
| 分組／替代 | `(ab)`、<code>a&#124;b</code> | 分組、a 或 b；例如 <code>Pattern.compile("cat&#124;dog")</code> |
| 起點／終點 | `^`、`$` | 受 MULTILINE 等旗標影響 |

```java
String[] columns = "a.b.c".split(Pattern.quote("."));
String replaced = "費用 120 元".replaceAll("\\d+", "#");
String literalReplacement = Matcher.quoteReplacement("$100");
String safe = "price=10".replaceAll("10", literalReplacement);
```

Pattern.quote 將搜尋文字視為字面值；Matcher.quoteReplacement 處理替換文字中的 `$` 與反斜線。Pattern 可共用，Matcher 有狀態，不適合跨執行緒共用。固定規則重複使用時先 compile，避免每次重建。

## java.util.Objects：null 與相等

```java
import java.util.Objects;
```

```java
String left = null;
String right = "Java";
boolean same = Objects.equals(left, right); // null-safe
String fallback = Objects.requireNonNullElse(left, "未命名");
String checked = Objects.requireNonNull(right, "名稱不可為 null");
int hash = Objects.hash("Amy", 80);
```

requireNonNull 失敗拋 NullPointerException；不會驗證空字串。Objects.hash 適合組合多欄位 hashCode，但 equals 與 hashCode 仍須使用一致的欄位。

## UUID 與 Base64

```java
import java.util.UUID;
import java.util.Base64;
import java.nio.charset.StandardCharsets;
```

```java
String id = UUID.randomUUID().toString();
UUID restored = UUID.fromString(id); // 非法格式拋 IllegalArgumentException
String encoded = Base64.getEncoder()
        .encodeToString("你好".getBytes(StandardCharsets.UTF_8));
String decoded = new String(Base64.getDecoder().decode(encoded), StandardCharsets.UTF_8);
String urlSafe = Base64.getUrlEncoder().withoutPadding()
        .encodeToString(new byte[]{1, 2, 3});
```

Base64 是編碼，不是加密。標準、URL-safe、MIME 編碼器有不同字元與換行規則，解碼時應匹配。UUID 適合作識別碼，但不能因此直接假定適合所有安全權杖情境。

## Properties：讀取設定檔

```java
import java.util.Properties;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.charset.StandardCharsets;
import java.io.IOException;
```

設定檔 `app.properties`：

```properties
app.name=速查工具
app.port=8080
```

以下放在可處理 IOException 的方法內：

```java
Properties props = new Properties();
try (var reader = Files.newBufferedReader(Path.of("app.properties"), StandardCharsets.UTF_8)) {
    props.load(reader);
}
String name = props.getProperty("app.name", "預設名稱");
int port = Integer.parseInt(props.getProperty("app.port", "8080"));
```

使用 Reader 可明確指定 UTF-8；load(InputStream) 使用 ISO-8859-1 規則。getProperty 的預設值處理「鍵不存在」，不代表既有設定值格式正確，數字與範圍仍需驗證。
