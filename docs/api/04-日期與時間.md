## 類別選擇與 import

```java
import java.time.*;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeParseException;
import java.time.format.ResolverStyle;
import java.time.temporal.ChronoUnit;
```

| 類別 | 使用情境 |
|---|---|
| LocalDate | 生日, 帳單日期, 沒有時間與時區 |
| LocalTime | 每日營業時間, 沒有日期與時區 |
| LocalDateTime | 尚未決定時區的日期時間, 不是時間線上的唯一瞬間 |
| ZonedDateTime | 帶地區時區, 考慮夏令時間規則 |
| OffsetDateTime | 帶 UTC 偏移量, 未包含完整地區時區規則 |
| Instant | 時間線上的一個瞬間, 適合事件時間戳 |
| Period | 年, 月, 日形式的日期差 |
| Duration | 秒, 奈秒形式的時間量 |
| Clock | 可注入的時間來源, 方便固定時間測試 |

## 建立, 運算與比較

```java
LocalDate date = LocalDate.of(2026, 10, 30);
LocalDate parsed = LocalDate.parse("2026-10-30");
LocalDate nextWeek = date.plusDays(7);
LocalDate nextMonth = date.plusMonths(1);
LocalDate firstDay = date.withDayOfMonth(1);
boolean earlier = date.isBefore(nextWeek);
long days = ChronoUnit.DAYS.between(date, nextWeek); // 7
Period difference = Period.between(date, nextWeek);
Duration elapsed = Duration.between(Instant.EPOCH, Instant.EPOCH.plusSeconds(90));
long seconds = elapsed.getSeconds(); // 90
```

日期時間類別多為不可變, plus/with 回傳新值. 月底加月份會按有效日期調整, 例如 1 月 31 日加一個月會變成 2 月最後一天. Period.getDays 只取得"日部分", 不是跨月份的總天數; 總天數用 ChronoUnit.DAYS.between.

## 格式化與嚴格解析

```java
DateTimeFormatter format = DateTimeFormatter.ofPattern("uuuu/MM/dd")
        .withResolverStyle(ResolverStyle.STRICT);
String display = LocalDate.of(2026, 10, 30).format(format);
try {
    LocalDate input = LocalDate.parse("2026/02/30", format);
    System.out.println(input);
} catch (DateTimeParseException e) {
    System.out.println("日期格式或日期內容無效");
}
```

| 格式符號 | 意義 |
|---|---|
| uuuu | 年; 嚴格解析常用 |
| MM / dd | 月/日 |
| HH / hh | 24 小時/12 小時 |
| mm / ss | 分/秒 |
| XXX | UTC 偏移量, 例如 +08:00 |

不要誤用 YYYY (週基準年)當一般年份. DateTimeFormatter 可安全共用.

## 時區, 時間戳與固定時間來源

```java
ZoneId taipei = ZoneId.of("Asia/Taipei");
Instant now = Instant.now();
ZonedDateTime local = now.atZone(taipei);
ZonedDateTime utc = local.withZoneSameInstant(ZoneId.of("UTC"));
long epochMillis = now.toEpochMilli();
Instant restored = Instant.ofEpochMilli(epochMillis);
LocalDateTime wallTime = LocalDateTime.of(2026, 10, 30, 9, 0);
Instant event = wallTime.atZone(taipei).toInstant();

Clock fixed = Clock.fixed(Instant.parse("2026-10-30T00:00:00Z"), taipei);
LocalDate today = LocalDate.now(fixed);
```

LocalDateTime 轉成 Instant 必須有時區或偏移量. 有夏令時間的地區可能存在重複或不存在的當地時間, 排程需決定處理規則. 要保留同一瞬間使用 withZoneSameInstant, 不能只更換顯示上的小時數.
