## java.util: 選擇容器

| 需求 | 優先選擇 | 順序與限制 |
|---|---|---|
| 可重複, 依索引存取 | ArrayList | 保留插入順序; 中間增刪需搬移元素 |
| 去重 | HashSet | 不保證順序 |
| 去重且依插入順序 | LinkedHashSet | 保留插入順序 |
| 去重且排序 | TreeSet | 依比較器判斷重複與排序 |
| 依鍵查值 | HashMap | 不保證順序; 平均查找快 |
| 依鍵查值且保留插入順序 | LinkedHashMap | 更新既有鍵不會改其插入位置 |
| 依鍵排序 | TreeMap | 依鍵的比較器排序 |
| 佇列/堆疊 | ArrayDeque | 不允許 null |
| 優先取出最小值 | PriorityQueue | poll 才依優先順序; 遍歷不保證排序 |

本頁範例可使用 `import java.util.*;`; 實務可改為個別 import. 這些一般實作不保證同時修改的執行緒安全.

```java
import java.util.*;
```

## List: 增刪改查

```java
List<String> names = new ArrayList<>(List.of("Amy", "Bo"));
names.add("Chen");
names.add(0, "Dan");
String first = names.get(0);
names.set(1, "Ann");
names.remove("Bo");
names.removeIf(name -> name.length() < 3);
boolean exists = names.contains("Chen");
int size = names.size();
for (String name : names) System.out.println(name);
```

| 常用操作 | 使用方式/注意事項 |
|---|---|
| 依索引刪除 | `names.remove(0)`; 先檢查範圍 |
| 整數元素刪除 | `numbers.remove(Integer.valueOf(1))` 刪數值 1; remove(1) 刪索引 1 |
| 子清單 | `names.subList(0, 2)` 是原清單的視圖; 要獨立資料再包 new ArrayList |
| 轉陣列 | `names.toArray(String[]::new)` |
| 是否為空/清空 | `names.isEmpty()`/`names.clear()` |

## Set 與 Map

```java
Set<String> unique = new LinkedHashSet<>(List.of("a", "b", "a"));
boolean added = unique.add("c"); // 新增成功為 true
unique.remove("b");

Map<String, Integer> scores = new HashMap<>();
scores.put("Amy", 80);
scores.put("Amy", 85); // 同鍵更新
int score = scores.getOrDefault("Bo", 0);
scores.putIfAbsent("Bo", 70);
scores.merge("Amy", 5, Integer::sum); // 90
scores.computeIfAbsent("Chen", key -> 60);
for (Map.Entry<String, Integer> entry : scores.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
scores.remove("Bo");
```

`map.get(key)` 找不到回傳 null; 若 map 允許 null 值, 用 containsKey 區分. 鍵放入 HashMap 或元素放入 HashSet 後, 不要修改其 equals/hashCode 所依賴的狀態.

## 排序與工具

```java
int[] values = {3, 1, 2};
Arrays.sort(values);
System.out.println(Arrays.toString(values)); // [1, 2, 3]
int index = Arrays.binarySearch(values, 2); // 須先依相同規則排序

List<String> words = new ArrayList<>(List.of("pear", "fig", "apple"));
words.sort(Comparator.comparingInt(String::length)
        .thenComparing(Comparator.naturalOrder()));
words.sort(Comparator.reverseOrder());
Collections.reverse(words);
String largest = Collections.max(words); // 非空集合
```

Comparator 可使用 `nullsFirst`/`nullsLast` 處理 null. 避免用 `(a, b) -> a - b` 比較整數, 可能溢位; 改用 Integer.compare 或 comparingInt.

## Queue, Deque 與 PriorityQueue

```java
Deque<String> queue = new ArrayDeque<>();
queue.offerLast("A");
queue.offerLast("B");
String head = queue.peekFirst(); // A, 不移除; 空時 null
String removed = queue.pollFirst(); // A, 移除; 空時 null
queue.push("C"); // 堆疊: 從前端加入
String top = queue.pop(); // C; 空時拋例外

PriorityQueue<Integer> priority = new PriorityQueue<>();
priority.offer(3);
priority.offer(1);
int smallest = priority.poll(); // 1
```

## 不可修改與複製

| 寫法 | 行為 |
|---|---|
| `List.of(...)` / `Set.of(...)` / `Map.of(...)` | 不可修改且拒絕 null; Set.of 拒絕重複元素, Map.of 拒絕重複鍵 |
| `Arrays.asList(array)` | 固定大小, 與原陣列共用元素, 可 set, 不能 add/remove |
| `new ArrayList<>(source)` | 獨立容器的淺拷貝, 元素物件仍共用 |
| `List.copyOf(source)` | 不可修改的淺層快照, 拒絕 null |
| `Collections.unmodifiableList(source)` | 原清單的唯讀視圖, 原清單變更仍看得到 |

增強 for 中不要直接對原集合 add/remove; 用 removeIf 或 Iterator.remove (需集合支援).
