## java.lang: String

自動匯入. String 不可變, 所有修改操作需接住回傳值.

| 需求 | 使用方式 | 結果/限制 |
|---|---|---|
| 長度 | `"Java".length()` | 4; 計算 UTF-16 碼元數 |
| 單一碼元 | `"Java".charAt(0)` | 'J'; 索引超界拋例外 |
| 空字串 | `"".isEmpty()` | true |
| 空白文字 | `" \t".isBlank()` | true |
| 去除首尾空白 | `" Java ".strip()` | "Java"; trim 使用較舊的窄範圍規則 |
| 比較內容 | `"java".equalsIgnoreCase("JAVA")` | true |
| 包含/開頭/結尾 | `s.contains("ab")`, `s.startsWith("a")`, `s.endsWith("b")` | boolean |
| 找位置 | `"Java".indexOf("va")` | 2; 找不到為 -1 |
| 擷取 | `"Java".substring(1, 3)` | "av"; 含頭不含尾 |
| 文字替換 | `"a.b".replace(".", "-")` | "a-b", 不使用 regex |
| 正規替換 | `"a12".replaceAll("\\d", "#")` | "a##" |
| 切割 | `"a,b,".split(",", -1)` | 保留尾端空欄; 省略 -1 會丟棄尾端空欄 |
| 串接 | `String.join(",", "a", "b")` | "a,b" |
| 重複 | `"ab".repeat(2)` | "abab" |
| 格式化 | `String.format(java.util.Locale.ROOT, "%.2f", 3.5)` | "3.50" |
| 大小寫 | `s.toLowerCase(java.util.Locale.ROOT)` | 避免依系統語系改變識別文字 |

避免對 null 呼叫上述方法. 比較 nullable 字串可用 `java.util.Objects.equals(a, b)`.

## StringBuilder, 數值轉換與 Math

```java
StringBuilder builder = new StringBuilder();
builder.append("總額: ").append(150).append(" 元");
builder.insert(0, "本日 ");
String result = builder.toString();

int n = Integer.parseInt("42");
long big = Long.parseLong("8000000000");
double decimal = Double.parseDouble("3.5");
String text = String.valueOf(n);
```

轉換失敗會拋 NumberFormatException. Double.parseDouble 也接受 NaN, Infinity; 若業務只接受有限值, 用 `Double.isFinite(decimal)` 額外檢查.

| 方法 | 使用方式 |
|---|---|
| min / max | `Math.max(3, 8)` -> 8 |
| abs | `Math.abs(-3)` -> 3; 最小 int/long 的絕對值溢位需留意 |
| round | `Math.round(2.6)` -> 3L; 不是完整商業捨入策略 |
| floor / ceil | `Math.floor(2.9)` -> 2.0; `Math.ceil(2.1)` -> 3.0 |
| pow / sqrt | `Math.pow(2, 3)` -> 8.0; `Math.sqrt(9)` -> 3.0 |
| addExact / multiplyExact | `Math.addExact(a, b)`, 溢位時拋 ArithmeticException |

## java.math: BigDecimal 與 BigInteger

```java
import java.math.BigDecimal;
import java.math.BigInteger;
import java.math.RoundingMode;
```

```java
BigDecimal price = new BigDecimal("19.90");
BigDecimal total = price.multiply(BigDecimal.valueOf(3)); // 59.70
BigDecimal tax = total.multiply(new BigDecimal("0.05"));
BigDecimal payable = total.add(tax).setScale(2, RoundingMode.HALF_UP);
BigDecimal average = total.divide(BigDecimal.valueOf(7), 2, RoundingMode.HALF_UP);
boolean equal = new BigDecimal("2.0").compareTo(new BigDecimal("2.00")) == 0;
BigInteger huge = new BigInteger("99999999999999999999").add(BigInteger.ONE);
```

| 方法/規則 | 使用方式 |
|---|---|
| 建立 | 使用字串或 valueOf; 避免 `new BigDecimal(0.1)` 的二進位近似誤差 |
| 加減乘除 | add, subtract, multiply, divide; 都回傳新值 |
| 除法 | 除不盡且未指定捨入規則可能拋 ArithmeticException |
| 比較 | compareTo 回傳負數, 0, 正數; equals 還會比較 scale |
| 捨入 | HALF_UP 四捨五入; HALF_EVEN 中點取偶; DOWN 向零截斷 |
| 精確轉整數 | `payable.intValueExact()`; 有小數或超界會拋例外 |

## java.util: Scanner 與 Random

```java
import java.util.Scanner;
import java.util.Random;
```

```java
Scanner scanner = new Scanner(System.in);
System.out.print("請輸入年齡: ");
if (scanner.hasNextLine()) {
    try {
        int age = Integer.parseInt(scanner.nextLine().strip());
        if (age < 0) throw new IllegalArgumentException("年齡不可為負");
        System.out.println(age);
    } catch (IllegalArgumentException e) {
        System.out.println("請輸入非負整數");
    }
}
Random random = new Random();
int dice = random.nextInt(6) + 1; // 1 ~ 6; nextInt(bound) 不含 bound
double ratio = random.nextDouble(); // [0.0, 1.0)
```

統一 nextLine 再解析可避免 nextInt 留下換行. 關閉 Scanner 會關閉底層 System.in, 應由整體輸入的擁有者決定何時關閉. `new Random(123)` 可產生可重現序列; 安全權杖等用途使用 `java.security.SecureRandom`, 不要使用 Random.
