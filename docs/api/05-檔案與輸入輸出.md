## import 與責任

```java
import java.io.*;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
```

Path 表示路徑，Files 執行檔案操作；java.io 提供位元組／字元串流。以下檔案操作片段需放在 try/catch 中，或由所在方法宣告 `throws IOException`。

## Path 與基本操作

| 需求 | 寫法 | 注意事項 |
|---|---|---|
| 建立路徑 | `Path.of("data", "note.txt")` | 相對於程序工作目錄 |
| 組合路徑 | `base.resolve("note.txt")` | 若傳入絕對路徑會直接使用它 |
| 絕對路徑 | `path.toAbsolutePath()` | 不代表實際存在 |
| 正規化 | `path.normalize()` | 處理 . 與 ..，不解析符號連結 |
| 真實路徑 | `path.toRealPath()` | 路徑需存在，預設解析符號連結 |
| 父目錄／檔名 | `path.getParent()`／`path.getFileName()` | 單獨檔名的 parent 可能是 null |
| 建立目錄 | `Files.createDirectories(dir)` | 父目錄不存在也一併建立 |
| 查詢 | `Files.exists(path)`、`Files.isDirectory(path)` | 查詢後狀態仍可能改變 |
| 複製 | `Files.copy(src, dst)` | 預設不覆寫、不遞迴複製目錄內容 |
| 移動 | `Files.move(src, dst)` | 跨檔案系統等情況可能失敗 |
| 刪除 | `Files.deleteIfExists(path)` | 非空目錄不能直接刪除 |

## 小文字檔：讀、覆寫、追加

```java
Path path = Path.of("data", "note.txt");
Files.createDirectories(path.getParent());
Files.writeString(path, "第一行\n", StandardCharsets.UTF_8); // 覆寫
Files.writeString(path, "第二行\n", StandardCharsets.UTF_8,
        StandardOpenOption.CREATE, StandardOpenOption.APPEND);
String text = Files.readString(path, StandardCharsets.UTF_8);
java.util.List<String> lines = Files.readAllLines(path, StandardCharsets.UTF_8);
```

readString/readAllLines 整份載入記憶體；大檔案改逐行處理。覆寫重要檔案前先備份；writeString 不保證中斷或斷電時保留完整內容。

## 大文字檔與二進位檔

```java
Path source = Path.of("data", "note.txt");
try (BufferedReader reader = Files.newBufferedReader(source, StandardCharsets.UTF_8)) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line); // readLine 不含換行符號
    }
}

Path copy = Path.of("data", "copy.bin");
try (InputStream in = Files.newInputStream(source);
     OutputStream out = Files.newOutputStream(copy)) {
    in.transferTo(out);
}
```

InputStream/OutputStream 處理位元組；Reader/Writer 處理字元。圖片、壓縮檔等不要經文字解碼。`Files.readAllBytes(path)` 適合小型二進位檔。

## 列目錄、遞迴走訪與串流關閉

```java
Path dir = Path.of("data");
try (var paths = Files.list(dir)) { // 只列一層
    paths.filter(Files::isRegularFile).forEach(System.out::println);
}
try (var paths = Files.walk(dir)) { // 含起點，預設不追蹤符號連結
    paths.filter(Files::isRegularFile).forEach(System.out::println);
}
try (var lines = Files.lines(dir.resolve("note.txt"), StandardCharsets.UTF_8)) {
    long nonBlank = lines.filter(s -> !s.isBlank()).count();
    System.out.println(nonBlank);
}
```

這三種 Stream 持有檔案資源，必須關閉。Files.walk 只走訪，不會刪檔。處理外部傳入路徑時，需驗證最終路徑是否位於允許目錄內；單靠 normalize 不足以處理符號連結造成的路徑逸出。

## 複製與安全寫入的選項

```java
Files.copy(Path.of("data", "note.txt"), Path.of("data", "backup.txt"),
        StandardCopyOption.REPLACE_EXISTING);
```

REPLACE_EXISTING 會取代目的檔。若需要「完整寫好才替換」，先在同目錄寫暫存檔，再嘗試使用 `ATOMIC_MOVE` 移動；檔案系統不支援時會拋 AtomicMoveNotSupportedException，應明確決定退回策略。原子移動不等同斷電持久性保證。
