## 程式骨架與執行

```java
package demo;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> names = List.of("小明", "小華");
        System.out.println(names);
    }
}
```

儲存為 `Main.java`, 在所在目錄執行:

```powershell
javac -encoding UTF-8 -d out Main.java
java "-Dfile.encoding=UTF-8" -cp out demo.Main
```

| 寫法 | 使用方式與規則 |
|---|---|
| `package demo;` | 第一個非註解宣告; 命名所屬套件 |
| `import java.util.List;` | 讓本檔可使用簡稱 List; 不會匯入子套件 |
| `import static java.lang.Math.max;` | 可直接呼叫 `max(1, 2)` |
| `public class Main` | public 頂層類別名稱須與檔名相符 |
| `public static void main(String[] args)` | 程式入口, args 接收命令列參數 |
| `//`, `/* */`, `/** */` | 單行, 區塊, Javadoc 註解 |

## 型別, 變數與常數

| 型別 | 宣告例子 | 範圍或用途 |
|---|---|---|
| byte | `byte n = 127;` | -128 ~ 127 |
| short | `short n = 32000;` | -32768 ~ 32767 |
| int | `int n = 2_000_000;` | -2^31 ~ 2^31-1 |
| long | `long n = 8_000_000_000L;` | -2^63 ~ 2^63-1, 常值加 L |
| float | `float n = 0.5F;` | 32 位元近似浮點數 |
| double | `double n = 0.5;` | 64 位元近似浮點數 |
| boolean | `boolean ok = true;` | true 或 false, 不與整數互換 |
| char | `char c = '中';` | 一個 UTF-16 碼元; emoji 可能需兩個 |
| String | `String s = "你好";` | 不可變文字, 屬於參考型別 |
| 陣列 | `int[] a = {1, 2};` | 固定長度的參考型別 |

```java
final int LIMIT = 100;
var name = "小明"; // 推斷為 String, 不是動態型別
double widened = 3;
int truncated = (int) 3.9; // 3, 向零截斷
int parsed = Integer.parseInt("42");
String text = String.valueOf(parsed);
Integer boxed = 42; // 自動裝箱
int unboxed = boxed; // 自動拆箱; boxed 若是 null 就會出錯
```

`var` 只可用於可推斷型別且有初始值的區域變數等位置, 不能用於欄位或一般方法參數. 區域變數用前必須賦值; 欄位與陣列元素才有 0, false, null 等預設值. final 限制重新指定參考, 不保證物件內容不可變.

## 運算子

| 功能 | 寫法 | 使用重點 |
|---|---|---|
| 算術 | `+ - * / %` | `5 / 2 == 2`; `5.0 / 2 == 2.5`; `5 % 2 == 1` |
| 指定 | `= += -= *= /= %=` | `sum += x` 累加; 複合指定可能含隱式窄化轉型 |
| 遞增減 | `++ --` | `x++` 先取值再加, `++x` 先加再取值 |
| 比較 | `== != > >= < <=` | 物件的 == 比較參考, 內容多用 equals |
| 邏輯 | `&&`, `\|\|`, `!` | 且, 或, 非; 前兩者會短路求值 |
| 位元 | `&`, `\|`, `^`, `~` | 逐位元 AND, OR, XOR, 反轉 |
| 位移 | `<< >> >>>` | 左移, 保留符號右移, 補零右移 |
| 三元 | `ok ? a : b` | 條件為 true 選 a, 否則 b |
| 型別檢查 | `value instanceof String` | null 的結果為 false |

不熟悉優先序時用括號. 整數溢位通常不報錯, 可用 `Math.addExact` 偵測. int 除以 0 會拋例外; 浮點數除以 0 可能得到 Infinity 或 NaN.

## 字串, 跳脫與 null

```java
String name = null;
boolean same = "小明".equals(name); // false, 避免對 null 呼叫方法
boolean usable = name != null && !name.isBlank();
String line = "第一行\n第二行\t欄位\"引號\"\\反斜線";
String json = """
        {"name": "小明"}
        """; // text block: 起始三引號後必須換行
```

字串使用雙引號, char 使用單引號. `"分數: " + 1 + 2` 是"分數: 12", `"分數: " + (1 + 2)` 是"分數: 3". 文字區塊有共同縮排移除與結尾換行規則, 不保證字面縮排原樣保留.
