## 封裝, 建構子與 static

```java
class Account {
    private final String owner;
    private int balance;
    private static int count;

    Account(String owner) { this(owner, 0); }

    Account(String owner, int balance) {
        if (balance < 0) throw new IllegalArgumentException("餘額不可為負");
        this.owner = owner;
        this.balance = balance;
        count++;
    }

    void deposit(int amount) {
        if (amount <= 0) throw new IllegalArgumentException("金額必須為正");
        balance = Math.addExact(balance, amount);
    }

    int getBalance() { return balance; }
    static int getCount() { return count; }
}
```

使用: `Account account = new Account("小明");`, `account.deposit(100);`, `Account.getCount()`. static 計數只是單執行緒示例, 不具並行安全性.

| 語法 | 用法 |
|---|---|
| this.field | 區分物件欄位與同名參數 |
| this(...) | 呼叫另一個建構子; Java 17 必須在建構子第一行 |
| super(...) | 呼叫父類別建構子; 同樣必須在第一行, 不能與 this(...) 同時使用 |
| static | 屬於類別, 不能直接使用 this 或物件欄位 |
| final 欄位 | 每個物件建構完成前必須指定, 之後不可重新指定 |
| final 方法/類別 | 禁止覆寫/禁止繼承 |

未宣告任何建構子時, 編譯器才會提供無參數建構子.

## 存取範圍

| 修飾詞 | 可用範圍 |
|---|---|
| public | 其他程式可存取, 仍受所屬型別/模組可見性限制 |
| protected | 同套件; 跨套件子類別依受保護存取規則使用 |
| 不寫 | 同套件 |
| private | 所屬類別範圍, 巢狀類別亦有相關存取權 |

頂層類別不能宣告為 private 或 protected. 跨套件 protected 並不代表子類別可透過任意父類別物件取用成員.

## 繼承, 介面與多型

```java
interface Speaker {
    String speak();
    default String greeting() { return "你好, " + speak(); }
}

abstract class Animal {
    abstract String name();
}

class Dog extends Animal implements Speaker {
    @Override String name() { return "狗"; }
    @Override public String speak() { return "汪"; }
}
```

使用: `Speaker pet = new Dog();`, `pet.speak()`. 介面型別限制可呼叫的成員, 實際物件決定覆寫方法的行為.

| 語法 | 用途 |
|---|---|
| extends | 類別只可繼承一個父類別; 介面可 extends 多個介面 |
| implements | 類別可實作多個介面 |
| abstract | 抽象類別不能直接 new; 抽象方法沒有實作本體 |
| default | 介面提供預設實作; 衝突時實作類別需解決 |
| super.method() | 使用父類別方法實作 |
| @Override | 編譯器檢查是否正確覆寫; 不能縮小存取權限 |

方法覆寫與方法多載不同; static 方法是隱藏而非動態覆寫.

## enum, record 與 sealed

```java
enum Status {
    TODO, DONE;
    boolean isDone() { return this == DONE; }
}

record Point(int x, int y) {
    Point {
        if (x < 0 || y < 0) throw new IllegalArgumentException("座標不可為負");
    }
}

sealed interface Shape permits Circle, Rectangle {}
record Circle(double radius) implements Shape {}
record Rectangle(double width, double height) implements Shape {}
```

使用: `Status.DONE.isDone()`, `new Point(1, 2).x()`. record 自動產生存取方法, equals, hashCode, toString, 且本身為 final; 它是淺層不可變, 欄位指向的集合仍可能可變.

sealed 限制直接子型別; 直接子類別須為 final, sealed 或 non-sealed (record 隱含 final). 非具名模組中相關型別須位於同一套件.

## instanceof 與物件相等

```java
Object value = "Java";
if (value instanceof String text && !text.isBlank()) {
    System.out.println(text.length());
}
```

Java 17 可用 instanceof 模式變數, 依條件成立範圍使用. 自行覆寫 equals 時也要覆寫 hashCode, 且相等物件必須有相同 hashCode, 否則 HashSet/HashMap 查找可能異常. record 已產生兩者; 一般物件預設 equals 比較是否同一物件.
