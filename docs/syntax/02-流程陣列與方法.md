## 條件與分支

```java
int score = 82;
if (score >= 90) {
    System.out.println("優秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("未及格");
}

String grade = switch (score / 10) {
    case 10, 9 -> "A";
    case 8 -> "B";
    default -> {
        System.out.println("其他級距");
        yield "C"; // 區塊形式以 yield 交回 switch 的值
    }
};
```

| 寫法 | 用途與限制 |
|---|---|
| if / else if / else | 依順序只執行首個成立分支 |
| `case ... ->` | 不會落入下一分支; 可用於 switch 敘述與運算式 |
| `case ...:` | 傳統形式通常需要 break, 否則繼續執行下一分支 |
| switch 運算式 | 必須涵蓋所有可能情況; 通常加 default |

Java 17 非預覽的 switch 不支援 long, float, double, boolean, 也不支援型別模式 case; String 或包裝型別輸入為 null 時會出錯.

## 迴圈與跳轉

```java
for (int i = 0; i < 3; i++) {
    if (i == 1) continue; // 跳過本輪, for 仍會執行 i++
    System.out.println(i); // 0, 2
}
int remaining = 3;
while (remaining > 0) {
    remaining--;
}
do {
    remaining++;
} while (remaining < 1); // 至少執行一次
```

| 指令 | 使用方式 |
|---|---|
| `break;` | 離開最近的一層迴圈或 switch |
| `continue;` | 跳過目前迴圈本輪後續內容 |
| `return;` | 結束 void 方法 |
| `return value;` | 結束方法並交回值 |
| `break outer;` | 離開標籤 outer 所指的外層區塊/迴圈 |

```java
outer:
for (int row = 0; row < 3; row++) {
    for (int col = 0; col < 3; col++) {
        if (row == 1 && col == 1) break outer;
    }
}
```

標籤可用於多層搜尋; 邏輯複雜時通常拆方法更易讀.

## 陣列

```java
int[] values = {10, 20, 30};
int[] emptySlots = new int[3]; // 元素預設為 0
values[0] = 99;
for (int value : values) System.out.println(value);

int[][] grid = {{1, 2}, {3, 4, 5}}; // 各列可不同長度
for (int[] row : grid) {
    for (int cell : row) System.out.println(cell);
}
int[] copy = values.clone();
```

| 操作 | 寫法與注意事項 |
|---|---|
| 長度 | `values.length`, 不是 length() |
| 取值 | `values[index]`; 索引為 0 ~ length-1 |
| 複製 | `clone()` 為淺拷貝; 物件陣列的元素仍指向原物件 |
| 指定 | `int[] alias = values;` 沒有複製, 是共用陣列 |
| 比較內容 | `java.util.Arrays.equals(a, b)`; 多維用 deepEquals |
| 遍歷改值 | 增強 for 中重新指定 value 不會改到原陣列元素, 需使用索引 |

## 方法, 多載與可變參數

以下放在類別內, main 外:

```java
static int add(int a, int b) { return a + b; }
static double add(double a, double b) { return a + b; }

static int sum(int... values) { // 可變參數必須放最後, 只能有一組
    int total = 0;
    for (int value : values) total += value;
    return total;
}

static void checkAge(int age) {
    if (age < 0) throw new IllegalArgumentException("年齡不可為負數");
}
```

在 main 內呼叫 `add(1, 2)`, `add(1.5, 2.0)`, `sum(1, 2, 3)`, `sum()`. 多載由參數型別與數量區分, 不能只更換回傳型別.

Java 一律傳值: 基本型別複製數值, 物件複製參考值. 方法內可以透過參考修改物件內容, 但把參數重新指向另一個物件, 不會換掉呼叫端的變數參考.
